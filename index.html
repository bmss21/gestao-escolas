Configurar Firebase

Cole aqui o firebaseConfig do seu projeto Firebase (Consola Firebase → Definições do projeto → As suas apps). É guardado apenas neste dispositivo/navegador.

Certifique-se de que ativou Authentication (Email/Password) e Firestore Database nesse projeto.
